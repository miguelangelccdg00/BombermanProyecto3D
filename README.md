# 🎮 Bomberman 3D

![Bomberman 3D Game](Assets/mainMenu.png)

A modern 3D reimagining of the classic Bomberman game, built with Unity. This project brings the beloved grid-based bombing action into a three-dimensional space while maintaining the core gameplay mechanics that made the original game so engaging.

## ✨ Features

### 🎯 Game Modes
- **Campaign Mode**: Progress through multiple levels of increasing difficulty
- **Fast Game**: Jump straight into action with quick match options
- **Level Selection**: Choose from different battle arenas

### 🎪 Gameplay Elements
- **3D Movement**: Full 3D character control with smooth animations
- **Two-Player Support**: Local multiplayer with different control schemes
  - Player 1: WASD movement, Space for bombs
  - Player 2: Arrow keys movement, Enter for bombs
- **Life System**: Multiple lives per player with visual UI indicators
- **Dynamic Battles**: Strategic bomb placement and power-ups

### 🎨 Visual Features
- Modern 3D graphics
- Animated character models
- Visual effects for explosions
- UI elements for lives and game status

## 🎯 Controls

### Player 1
- **Movement**: WASD keys
- **Place Bomb**: Space bar

### Player 2
- **Movement**: Arrow keys
- **Place Bomb**: Enter/Return key
